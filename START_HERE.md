# 🎯 УВП - Система Управления Временем Проектов

## 📦 Что внутри

Вы получили полнофункциональный Django-проект для управления проектами со следующими возможностями:

### ✅ Реализованные функции

1. **Управление проектами**
   - Создание, редактирование, удаление проектов
   - Статусы проектов (запланирован, в работе, простой, заморожен)
   - Загрузка логотипов проектов
   - Теги для категоризации
   - Управление командой проекта с ролями

2. **Задачи**
   - CRUD операции с задачами
   - Статусы задач (todo, in progress, done)
   - Назначение исполнителей
   - Отслеживание планируемого и фактического времени
   - Теги для задач

3. **Финансовый учёт**
   - Доходы и расходы по проектам
   - Категории операций
   - Автоматический расчёт балансов
   - История операций

4. **Доступы к ресурсам**
   - Хранение логинов и паролей
   - Маскирование паролей в интерфейсе
   - URL и Drive ссылки
   - Отслеживание стоимости подписок

5. **Медиафайлы**
   - Загрузка файлов (изображения, документы, видео)
   - Предпросмотр изображений
   - Привязка к проектам

6. **Визуализация структуры (Rete.js)**
   - Графическое отображение структуры проекта
   - Перетаскивание узлов задач
   - Сохранение позиций
   - Автоматическое размещение

7. **REST API**
   - Полный CRUD для всех сущностей
   - Фильтрация и поиск
   - Пагинация
   - Документация

8. **Права доступа**
   - Глобальные роли (SA, Admin, Manager, Guest)
   - Роли в проекте (Owner, Member, Customer)
   - Матрица прав доступа

## 🚀 Быстрый старт

### Вариант 1: Автоматическая установка (рекомендуется)

```bash
cd uvp_project
chmod +x setup.sh
./setup.sh
```

Скрипт выполнит всё автоматически!

### Вариант 2: Ручная установка

```bash
# 1. Создать виртуальное окружение
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Создать .env файл
cp .env .env
# Отредактируйте .env, установите SECRET_KEY

# 4. Применить миграции
python manage.py makemigrations
python manage.py migrate

# 5. Создать суперпользователя
python manage.py createsuperuser

# 6. Создать группы пользователей
python manage.py shell
>>> from apps.users.models import GroupUsers
>>> GroupUsers.objects.create(name='admin')
>>> GroupUsers.objects.create(name='manager')
>>> GroupUsers.objects.create(name='guest')
>>> exit()

# 7. Собрать статику
python manage.py collectstatic --noinput

# 8. Запустить сервер
python manage.py runserver
```

### Откройте в браузере

- **Приложение:** http://127.0.0.1:8000
- **Админ-панель:** http://127.0.0.1:8000/admin
- **API:** http://127.0.0.1:8000/api/

## 🔐 Роли и права

### Глобальные роли
- **SA (Super Admin)** - полный доступ ко всему
- **Admin** - управление своими проектами и пользователями
- **Manager** - управление проектами с ограничениями
- **Guest** - только просмотр

### Роли в проекте
- **Owner** - владелец проекта, полный контроль
- **Manager** - управление задачами и участниками
- **Member** - участник, работа с задачами
- **Viewer** - только чтение
