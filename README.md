# УВП — Система Управления Временем Проектов

## Описание

УВП — это полнофункциональное веб-приложение для комплексного управления проектами, задачами, финансовыми потоками и
доступами. Особенностью системы является визуализация связей между элементами проекта с помощью интерактивных графов, а
также глобальная карта всех проектов ("Супер-структура").

## Основные возможности

### 1. Управление проектами

* Полный цикл CRUD операций для проектов.
* Система статусов: «Запланирован», «В работе», «Простой», «Заморожен», «Завершен».
* Управление командами проекта с разграничением ролей (Владелец, Участник, Заказчик).
* Категоризация через гибкую систему тегов.

### 2. Задачи и подзадачи

* Создание задач и подзадач с возможностью назначения исполнителей.
* Учет планируемого и фактического времени выполнения.
* Отслеживание прогресса через статусы (todo, in progress, done).
* Визуализация зависимостей между задачами.

### 3. Финансовый учет (Биллинг)

* Фиксация доходов и расходов по конкретным проектам.
* Автоматический расчет баланса проекта.
* Категоризация транзакций (планируемые/утвержденные расходы, ожидаемые/фактические доходы).

### 4. Менеджер доступов

* Безопасное хранение URL, логинов и паролей к внешним ресурсам.
* Маскирование паролей в интерфейсе для предотвращения утечек.
* Возможность указания ссылки на Google Drive.

### 5. Визуализация (Rete.js)

* **Структура проекта:** Интерактивный редактор графа для каждого проекта (задачи, финансы, доступы, медиафайлы).
* **Супер-структура:** Глобальная визуализация всех проектов и их владельцев для администраторов (позволяет видеть общую
  картину загрузки и связей).

## Технологический стек

* **Backend**: Django 5.x, Django REST Framework.
* **Frontend**: Jinja2 Templates, Bootstrap 5, HTMX, Alpine.js.
* **База данных**: PostgreSQL (Production), SQLite (Development).
* **Визуализация**: Rete.js.
* **Контейнеризация**: Docker, Docker Compose.

## Быстрый старт

### Вариант 1: Локальный запуск (Python)

1. **Подготовка окружения**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   # venv\Scripts\activate   # Для Windows
   pip install -r requirements.txt

```

2. **Настройка БД и запуск**

```bash
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver

```

### Вариант 2: Запуск через Docker

1. **Сборка и запуск**

```bash
docker-compose up -d --build

```

2. **Применение миграций и создание администратора**

```bash
docker-compose exec web python manage.py migrate
docker-compose exec web python manage.py createsuperuser

```

Приложение будет доступно по адресу: `http://127.0.0.1:8000`.

## Роли в системе

### Глобальные роли (Группы):

* **Admin**: Полный доступ ко всем разделам, управлению пользователями и "Супер-структуре".
* **Guest**: Ограниченный доступ (только чтение или базовые функции).

### Проектные роли:

* **Владелец (Owner)**: Полный контроль над настройками, составом проекта и его структурой.
* **Участник (Member)**: Работа с задачами, изменение статусов, загрузка файлов.
* **Заказчик (Customer)**: Просмотр общего прогресса (Progress Bar) и финансовой сводки, без доступа к деталям задач.
