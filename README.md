# УВП — Система Управления Временем Проектов

## Описание

УВП — это полнофункциональное веб-приложение для комплексного управления проектами, задачами, финансовыми потоками и доступами. Особенностью системы является визуализация связей между элементами проекта с помощью интерактивных графов.

## Основные возможности

### 1. Управление проектами

* Полный цикл CRUD операций для проектов.
* Система статусов: «Запланирован», «В работе», «Простой», «Заморожен», «Завершен».
* Управление командами проекта с разграничением ролей (Владелец, Участник, Заказчик).
* Категоризация через гибкую систему тегов.

### 2. Задачи и подзадачи

* Создание многоуровневых задач с возможностью назначения исполнителей.
* Учет планируемого и фактического времени выполнения.
* Отслеживание прогресса через статусы (todo, in progress, done).

### 3. Финансовый учет (Биллинг)

* Фиксация доходов и расходов по конкретным проектам.
* Автоматический расчет баланса проекта.
* Категоризация транзакций (планируемые/утвержденные расходы, ожидаемые/фактические доходы).

### 4. Менеджер доступов

* Безопасное хранение URL, логинов и паролей к внешним ресурсам.
* Маскирование паролей в интерфейсе для предотвращения утечек.
* Связь доступов с конкретными проектами и тегами.

### 5. Визуализация структуры (Rete.js)

* Интерактивный редактор структуры проекта в виде графа.
* Drag-and-drop управление узлами (задачи, финансы, доступы).
* Сохранение позиций и связей между элементами напрямую в БД.

## Технологический стек

* **Backend**: Django 5.x, Django REST Framework.
* **Frontend**: Jinja2 Templates, Bootstrap 5, HTMX, Alpine.js.
* **База данных**: PostgreSQL (Production), SQLite (Development).
* **Визуализация**: Rete.js.

## Быстрый старт

### 1. Подготовка окружения

```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# venv\Scripts\activate   # Для Windows
pip install -r requirements.txt

```

### 2. Настройка БД и запуск

Вы можете использовать скрипт автоматической установки (только для Linux/macOS):

```bash
chmod +x setup.sh && ./setup.sh

```

**Или вручную:**

```bash
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver

```

Приложение будет доступно по адресу: `http://127.0.0.1:8000`.

## Роли в системе

### Глобальные роли (Группы):

* **Admin**: Полный доступ ко всем разделам и управлению пользователями.
* **Manager**: Создание и управление своими проектами.
* **Guest**: Режим только для чтения.

### Проектные роли:

* **Владелец (Owner)**: Полный контроль над настройками и составом проекта.
* **Участник (Member)**: Работа с задачами и файлами.
* **Заказчик (Customer)**: Просмотр общего прогресса и финансовой сводки.
