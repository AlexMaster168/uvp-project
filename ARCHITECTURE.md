# Архитектура проекта УВП

## Обзор

УВП (Управление Временем Проектов) построен на основе Django с использованием модульной архитектуры приложений. Проект следует паттерну MVT (Model-View-Template) с дополнительным REST API слоем.

## Структура приложений

### 1. Users (apps/users/)
**Назначение:** Управление пользователями, аутентификация и авторизация.

**Модели:**
- `GroupUsers` - группы пользователей (admin, manager, guest)
- `User` - расширенная модель пользователя Django

**Ключевые features:**
- **Google OAuth 2.0:** Интеграция с `django-allauth` для входа через Google.
- Кастомная модель пользователя с группами.
- Методы проверки ролей (is_super_admin, is_admin).
- API для управления профилем.

### 2. Projects (apps/projects/)
**Назначение:** Управление проектами и связанными сущностями.
**Ключевые features:** Визуализация структуры (Rete.js), финансовые итоги, иерархия.

### 3. Tasks (apps/tasks/)
**Назначение:** Управление задачами и подзадачами.

### 4. Billing (apps/billing/)
**Назначение:** Финансовый учёт по проектам (доходы/расходы).

### 5. Access (apps/access/)
**Назначение:** Безопасное хранение доступов (URL, логины, пароли).

### 6. MediaFiles (apps/media_files/)
**Назначение:** Управление загруженными файлами.

## Технологии и библиотеки

### Backend
- **Django 5.x** - основной фреймворк
- **Django REST Framework** - API
- **django-allauth** - социальная аутентификация (Google)
- **django-filter** - фильтрация
- **psycopg2** - PostgreSQL драйвер

### Frontend
- **Jinja2** - шаблонизатор
- **Bootstrap 5** - UI
- **HTMX & Alpine.js** - интерактивность
- **Rete.js** - визуализация графов

## Безопасность

### Аутентификация
- **Session Auth:** Стандартная сессионная аутентификация Django.
- **OAuth 2.0:** Безопасный вход через провайдера Google.

### Защита данных
- Маскирование паролей в модуле Access.
- CSRF токены для всех POST запросов.
- ENV-переменные для секретных ключей.
